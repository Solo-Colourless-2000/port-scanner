# 第984版 精読による問題抽出と修正

## 直接再現した仕様の不一致

960版の `read_report` に、UTF-16・UTF-32・UTF-8 BOM付きで書き込んだ正しいJSONを渡すと、3形式とも受理された。理由は `json.loads(raw)` へbytesを直接渡したため、パーサーによる文字コード自動判定が働くこと。教材の「UTF-8 JSON」と一致しない。

今回の修正はUTF-8での文字列変換をパースより前に移すこと。再現ケース3形式と、不正UTF-8バイト列の拒否を回帰テストで確認した。原典のソース内容は変更していない。

## 別途精読した原典の解説

Docker Composeの全capability、DNSのTCP/UDP公開、ScapyのACK応答待ち、Nmap出力、Postgres pg_hba.conf、OpenSSLフックのバッファ、Goの:=など、12箇所の解説を具体的な挙動と危険性に合わせて修正した。原典コードそのものは書き換えず、現状の制約として説明する。

## 監査方法の限界

後続の24周は複数項目を再実行する自動反復検査であって、24回の人手による全文精読ではない。実行していない原典の攻撃的コードや脆弱Docker環境について動作成功を主張しない。ブラウザのリロード後の進捗復元も未実測。
