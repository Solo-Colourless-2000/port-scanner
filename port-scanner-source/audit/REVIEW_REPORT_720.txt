FINDINGS AND SEMANTIC EDITS IN THIS REVISION
1. The standalone report comparator previously accepted different per-port timeout_seconds values for before and after. Such measurements are not directly comparable as the threshold affects the meaning of 'timeout'. compare() now rejects differing timeout values and records the agreed timeout and scope in the output.
2. timestamp_utc accepted timezone-aware +09:00 or other non-UTC offsets, even though the key specifically promises UTC. read_report() now requires zero UTC offset, distinguishing a valid ISO timestamp from a valid value for this specific schema field.
3. Declared scope strings in JSON could contradict the target IPv4. read_report() now checks loopback-only declaration, canonical RFC1918 CIDRs at /24 or narrower, and membership of the target in the CIDR. This remains a claimed scope, NOT evidence of legal authorization, IP ownership or source authenticity.
4. IPv4Network(..., strict=True) can throw a general ValueError for non-network addresses such as 192.168.56.3/24 with host bits set. Both scanner.py and report_diff.py now handle ValueError and transform invalid input into useful errors instead of showing an unexpected traceback.
5. The interleaved HTML lesson was fully synchronized with the revised independent files. Changed and inserted source lines have individually authored, context-specific Japanese explanations, including a breakdown of the actual variables, expressions, types, error cases, expected output, and neighboring source lines. Unmodified source lines retain their previous reviewed explanations.
6. New standalone beginner/recruiting document: portfolio_lab/docs/MEASUREMENT_COMPARABILITY_AND_EVIDENCE.md. It includes local-only command-by-command usage, input/exception rationale, safe failure cases, Git provenance, hashes and limits on what each evidential artifact proves, test instructions, and specific interview-ready design claims.
