# 検証記録を置く場所

このフォルダは、受講者自身がloopbackまたは許可済み隔離ラボで取得した証拠を整理するためのものです。サンプル制作時点ではユーザー自身による検証証拠は含まれません。

* 公開に適した例：OS/Pythonバージョン、実行日時、検査した127.0.0.1のポート、実行コマンド、実測した成功/失敗、テスト結果、コミットID。
* 公開しない情報：会社のIPアドレス・内部ホスト名、認証情報、顧客情報、個人の接続先、第三者の許可なしに得た結果。
* JSON出力や画像を公開するときは内容を人が再確認してください。`.gitignore` に一致しないファイルは自動的にGitの管理対象になる場合があります。
* 正常系と異常系の両方を検証し、`docs/TEST_REPORT_TEMPLATE.md` を実測値で埋めてください。架空の結果を記入しないでください。
